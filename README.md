# Folio

A simple, clean PDF reader for Windows.

## Download

**[⬇ Download Folio for Windows](https://github.com/mberman84/folio-releases/releases/latest/download/Folio-Setup.exe)** — run the installer; Folio keeps itself up to date automatically.

Prefer not to install? [Folio-Portable.exe](https://github.com/mberman84/folio-releases/releases/latest/download/Folio-Portable.exe) runs as-is (portable copies don't auto-update).

> Windows may show "Windows protected your PC" the first time because the app isn't code-signed yet. Click **More info → Run anyway**.

All versions: [Releases](https://github.com/mberman84/folio-releases/releases)
